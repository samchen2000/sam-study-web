1. Lens Shading 物理成因與數學模型

Cosine Fourth Law (\(\cos^4\theta\) 法則)

光學自然暗角 (Natural Vignetting)。根據光學幾何學，離軸光線到達感光元件的照度與入場角 \(\theta\) 的四次方成正比： \[ E(\theta) = E_0 \cdot \cos^4(\theta) \] 當角度越大（越接近鏡頭邊緣），光線照度衰減越嚴重，導致畫面四角顯著變暗。

光學機械遮擋 (Optical Vignetting)

鏡頭內部的鏡片筒身、光圈開口或濾鏡邊緣對傾斜入場的光線產生物理物理遮蔽。離軸極限角度的光束會被「裁切」(Vignetted)，使邊緣入射的光束截面積小於中心，進一步加劇邊緣亮度下降。

CRA Mismatch (主光角不匹配)

CMOS 微透鏡 (Microlens) 與鏡頭出射主光角 (Chief Ray Angle) 不匹配。大角度入射光無法完全聚焦在感光二極體 (Photodiode) 內部，部分光線被金屬互連層遮擋，甚至造成 Color Shading (色偏陰影)。

補償數學模型 (Mathematical Compensation Models)

1. 二項多項式徑向模型 (Polynomial Gain Curve)

假設 Lens Shading 以影像中心點 \((c_x, c_y)\) 呈圓形對稱衰減，定義正規化距離 \(r = \sqrt{\frac{(x-c_x)^2 + (y-c_y)^2}{R_{max}^2}}\)：

\( Gain(r) = 1 + k \cdot r^2 + \gamma \cdot r^4 \)

校正後畫素：\( I_{corrected}(x,y) = I_{raw}(x,y) \times Gain(r) \)

2. 工業級 17x17 Grid Mesh 網格擬合法

硬體 ISP 常將畫面切割為 \(17 \times 17\) 個區域節點，記錄每個節點的 R, Gr, Gb, B 增益倍數（Gain Table）。在硬體執行時透過雙線性插值 (Bilinear Interpolation) 計算每個畫素的精確補償值。

\( GainMap[i][j] \in [1.0, 4.0] \)

import cv2
import numpy as np
import matplotlib.pyplot as plt

def generate_lens_shading_gain_map(height, width, k=1.2, gamma=2.0, center_offset=(0, 0)):
    """
    【Sam 影像處理小幫手 - 函數說明】
    計算 2D Lens Shading 補償增益圖 (Gain Map)。

    參數 (Parameters):
        height (int): 影像高度
        width (int): 影像寬度
        k (float): 暗角補償強度係數 (Gain Compensation Intensity)
        gamma (float): 衰減指數 (Exponential Roll-off Factor)
        center_offset (tuple): 預留之非對稱中心偏移量 (dx, dy)，單位為像素
        
    傳回 (Returns):
        np.ndarray: shape (height, width) 的 float32 增益矩陣
    """
    # 1. 建立影像 X, Y 座標網格
    y_indices, x_indices = np.indices((height, width), dtype=np.float32)

    # 2. 計算光學中心 (預留非對稱偏移量 dx, dy)
    cx = (width / 2.0) + center_offset[0]
    cy = (height / 2.0) + center_offset[1]

    # 3. 計算各點至光學中心之歐式距離 r
    dx = x_indices - cx
    dy = y_indices - cy
    dist_sq = dx**2 + dy**2

    # 4. 最大可能距離的平方 (用於將距離正規化至 [0, 1])
    max_dist_sq = (width / 2.0)**2 + (height / 2.0)**2

    # 5. 正規化半徑 (Normalized Radius, 範圍 0.0 ~ 1.0)
    r_norm = np.sqrt(dist_sq / max_dist_sq)

    # 6. 多項式增益模型計算: Gain(r) = 1 + k * (r^gamma)
    gain_map = 1.0 + k * (r_norm ** gamma)

    return gain_map


def apply_lens_shading_correction(image_bgr, k=1.2, gamma=2.0, channel_gains=(1.0, 1.0, 1.0)):
    """
    對輸入 BGR 影像進行 Lens Shading 畫素補償。

    參數:
        image_bgr (np.ndarray): 輸入之 uint8 BGR 影像
        k (float): 補償強度
        gamma (float): 曲線指數
        channel_gains (tuple): (B_gain, G_gain, R_gain) 預留 RGB 獨立通道微調係數

    傳回:
        np.ndarray: 校正後之 uint8 BGR 影像
    """
    h, w, c = image_bgr.shape

    # 生成基礎 2D 增益圖
    base_gain_map = generate_lens_shading_gain_map(h, w, k=k, gamma=gamma)

    # 將 uint8 影像轉換為 float32 進行精確乘法運算
    img_float = image_bgr.astype(np.float32)
    corrected_img = np.zeros_like(img_float)

    # 分別對 B, G, R 三個通道進行增益乘法
    for ch in range(3):
        # 結合通道專屬微調係數
        ch_gain = base_gain_map * channel_gains[ch]
        corrected_img[:, :, ch] = img_float[:, :, ch] * ch_gain

    # 【預留擴充功能 - 屏蔽/備用區】
    # ---------------------------------------------------------------------
    # 1. 預留：過曝截斷預防 (Clipping Avoidance / Soft Knee Mapping)
    # corrected_img = np.clip(corrected_img, 0, 255)
    #
    # 2. 預留：將 2D Gain Map 降採樣為 17x17 網格並進行雙線插值 (Mesh Simulation)
    # grid_gain_17x17 = cv2.resize(base_gain_map, (17, 17), interpolation=cv2.INTER_AREA)
    # interpolated_gain = cv2.resize(grid_gain_17x17, (w, h), interpolation=cv2.INTER_LINEAR)
    # corrected_img[:, :, ch] = img_float[:, :, ch] * interpolated_gain
    # ---------------------------------------------------------------------

    # 數值數值數值數值截斷至 [0, 255] 並轉回 uint8
    corrected_img = np.clip(corrected_img, 0, 255).astype(np.uint8)

    return corrected_img, base_gain_map


def generate_17x17_grid_mesh(gain_map):
    """
    將全尺寸增益圖採樣為 17x17 網格點矩陣 (Mesh Table)
    """
    grid_17x17 = cv2.resize(gain_map, (17, 17), interpolation=cv2.INTER_AREA)
    return grid_17x17
