數學計算公式：
R' = (R * Rr) + (G * Rg) + (B * Rb)
G' = (R * Gr) + (G * Gg) + (B * Gb)
B' = (R * Br) + (G * Bg) + (B * Bb)
* 註：為了維持影像總亮度不變，矩陣每一橫列（Row）的加總理想上應等於 1.0（例如 Rr+Rg+Rb = 1）。
