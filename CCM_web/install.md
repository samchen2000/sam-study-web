## 1. 專案建立方式
你先建立專案：  
```
npm create vite@latest colorchecker-pro-web -- --template react-ts
cd colorchecker-pro-web
```
## 2. 安裝依賴
```
npm install fabric zustand react-dropzone react-hot-toast
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

## 3. 啟動方式
```
npm run dev
```
# 或 Docker：
```
docker compose up
```
