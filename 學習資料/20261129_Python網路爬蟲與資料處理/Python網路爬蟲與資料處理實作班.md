### 一、認識Python與編譯環境、資料型態I（數值、字串）
1. Python 編譯環境 : 
- 在開始寫程式前，需要了解 Python 的運作方式與撰寫工具。
    - 直譯式特性。 Python 透過直譯器逐行讀取並執行程式碼，不需要像傳統編譯語言那樣先耗時編譯整份檔案。程式執行時會自動判斷資料型態，讓語法保持簡短與高度彈性。
    - 雲端免安裝環境。 新手最推薦使用 Google Colab(https://colab.research.google.com/)，只要打開瀏覽器就能直接寫程式與執行，省去本機環境設定的麻煩。
    - 本機開發環境。 若要在電腦端長期開發，可先至 Python 官方網站(https://www.python.org/downloads/) 下載核心程式，再搭配 VS Code 編輯器或 Anaconda 套件管理工具來撰寫專案。
2. 資料型態I : 數值（Numeric）
- 數值型態專門用來儲存數字與進行數學計算，在宣告變數時不需要特別指定型別。
    - 整數（int）。 用來表示沒有小數點的正負整數與零，例如 10、-50 或 0。
    - 浮點數（float）。 用來表示帶有小數點的數值，例如 3.14、-0.5 或 2.0。
    - 布林值（bool）。 在 Python 中屬於整數的子類別，只有 True（真，等同於 1）與 False（假，等同於 0）兩種狀態，常用於邏輯判斷。
    - 常用算術運算子。 除了基本的加減乘除（+、-、*、/），Python 還支援取整數商數（//）、取餘數（%）以及次方運算（**）。
3. 資料型態 I ： 字串（String）
- 字串（str）用來處理文字與符號資訊，在 Python 中具備「不可變性」，建立後無法直接修改其中單一字元。
    - 建立方式。 文字內容必須使用成對的單引號（' '）或雙引號（" "）包起來，若為多行文字則可使用三個引號（""" """）。
    - 串接與重複。 使用加號（+）可以將兩個字串頭尾相連，使用乘號（*）則可以讓字串重複出現指定次數。
    - 索引與切片。 透過中括號 [] 可以取出特定位置的字元，且編號（索引值）固定從 0 開始計算。
4. 型態檢查與轉換
- 不同資料型態無法直接混合運算，例如將數字與字串相加會導致程式報錯。

| 內建函式 | 功能說明 | 使用範例 | 執行結果 |
| ---- | ---- | ---- | ---- |
| type() | 檢查資料目前的型態 | type(3.14) | <class 'float'> |
| int()	| 將浮點數或純數字字串轉為整數 | int("100") + 5	| 105 |
| float() | 將整數或數字字串轉為浮點數 | float("3.5") | 3.5 |
| str()	| 將數值轉為字串以便與文字串接 | "年齡：" + str(18) | "年齡：18" |

### 二、資料型態II（清單、字典）、定型化內容產出實作 
Python 的容器型別用來在單一變數中一次儲存多筆資料。 根據資料是否需要順序、能否修改以及是否允許重複，主要分為串列（list）、元組（tuple）、字典（dict）與集合（set）四種。
1. 在選擇要使用哪種容器前，可以先透過下表快速掌握它們的核心差異。

| 容器名稱 | 關鍵字 | 括號符號 | 是否有序 | 能否修改 | 允許重複資料 | 適用情境 |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| 串列 | list | [ ] | 有序 | 可以 | 允許 | 儲存需要隨時新增、刪除或排序的清單 |
| 元組 | tuple | ( ) | 有序 | 不可 | 允許 | 儲存固定不變的設定值（如座標、日期）|
| 字典 | dict | { } | 有序 | 可以 | 鍵不可重複 | 透過「名稱（鍵）」快速查詢對應的「內容（值）」 |
| 集合 | set | { } | 無序 | 可以 | 不允許 | 過濾重複項目，或進行交集、聯集等數學運算 |

2. 串列（List）：最靈活的資料清單
- 串列就像一張可隨時塗改的購物清單，裡面可以混合放進數字、字串甚至另一個串列。
    - **建立與取值**。 使用中括號 [] 建立資料，並透過從 0 開始的索引編號來讀取或修改特定位置的項目。
    - **新增與刪除**。 常用 .append() 將新資料加到清單最後面，或使用 .remove() 刪除指定的資料內容。
```python
# 建立串列
fruits = ["蘋果", "香蕉", "橘子"]

# 讀取與修改資料 (索引從 0 開始)
print(fruits[0])        # 印出：蘋果
fruits[1] = "草莓"      # 將第 2 個項目改為草莓

# 新增與刪除資料
fruits.append("葡萄")   # 在最後面加入葡萄
fruits.remove("蘋果")   # 刪除蘋果
print(fruits)           # 結果為 ['草莓', '橘子', '葡萄']
```
3. 元組（Tuple）：不可修改的安全清單
- 元組的操作方式與串列非常相似，但一旦建立後就無法新增、刪除或修改裡面的任何資料。
    - **建立與讀取**。 使用小括號 () 包住資料，同樣支援使用中括號 [] 搭配索引編號來讀取內容。
    - **存在意義**。 因為資料無法被意外更動，執行速度比串列更快，適合用來保護程式中的重要常數。
```python
# 建立元組 (例如經緯度座標)
location = (25.0330, 121.5654)

# 讀取資料
print(location[0])      # 印出：25.0330

# 若嘗試修改會直接報錯 (TypeError)
# location[0] = 24.0    # 這行執行會失敗
```
4. 字典（Dict）：鍵值對的查詢表
- 字典不依賴數字編號找資料，而是採用「鍵（Key）對應值（Value）」的方式來管理資訊。
    - **建立結構**。 使用大括號 {} 建立，每筆資料由 鍵: 值 組成，不同筆資料之間用逗號隔開。
    - **讀取與更新**。 在中括號內填入「鍵」的名稱即可取得對應的值，若指定的鍵不存在，直接賦值就會自動新增該筆資料。
```python
# 建立字典 (儲存學生資料)
student = {
    "name": "王小明",
    "age": 18,
    "scores": [85, 92, 78]
}

# 透過鍵 (Key) 讀取與修改資料
print(student["name"])          # 印出：王小明
student["age"] = 19             # 修改年齡為 19
student["city"] = "新北市"       # 新增 city 鍵值對

print(student)                  # 印出完整的更新後字典
```
5. 集合（Set）：自動去重的資料袋
- 集合專門用來處理不重複的資料群組，裡面的項目沒有固定順序，因此無法使用索引編號取值。
    - 自動過濾重複。 使用大括號 {} 建立（若為空集合需寫 set()），放進去的重複項目會自動被合併為一筆。
    - 集合運算。 支援用 & 找出兩組資料的共同項目（交集），或用 | 合併兩組資料（聯集）。
```python
# 建立集合 (重複的 2 會自動被移除)
nums_a = {1, 2, 2, 3, 4}
nums_b = {3, 4, 5, 6}

print(nums_a)               # 結果為 {1, 2, 3, 4}
print(nums_a & nums_b)      # 交集 (兩者皆有)：{3, 4}
print(nums_a | nums_b)      # 聯集 (全部合併)：{1, 2, 3, 4, 5, 6}
```
