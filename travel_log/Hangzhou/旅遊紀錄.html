第二天 : 7/20(星期一) 蔣村 -> 西溪國家濕地公園

1. 住宿地點走路到西溪國家濕地公園

  • 西溪國家濕地公園 。

    • 西溪國家濕地公園位於杭州市區西部，這裡環境清幽、水道縱橫，作為城市內的天然濕地在國內很是少見，有「杭州之腎」之稱。。

  • 施耐庵故居 。

    • 水滸傳作者的故居。

第三天 : 7/21(星期二) 蔣村 -> 西溪天街 -> 杭州百腦匯

1. 今天吃喝休息一天，去盒馬鮮生大採購，去往百腦匯，看一下數位產品。

  • 盒馬鮮生 。

    • 因為昨天走得太累了，所以休息一天，在飯店吃吃喝喝，去盒馬鮮生大採購。

  • 百腦匯 。

    • 去百腦匯看一下數位產品，回去碰到大雷雨，第一次打車回去。

第四天 : 7/22(星期三) 蔣村 -> 西溪菜市 -> 雷峰塔 -> 西湖風景區

1. 今天搭地鐵去雷峰塔與西湖。

  • 西溪菜市 。

    • 早上體驗杭州市場。

  • 雷峰塔 。

    • 雷峰塔是一座位於中國浙江省杭州市西湖南岸夕照山的著名佛塔，因民間傳說《白蛇傳》中法海將白娘子鎮壓於此而聞名。原塔建於西元975年，於1924年倒塌，現存的現代新塔是在原址重建的觀光景點。

  • 西湖風景區 。

    • 杭州西湖風景名勝區是中國著名的世界文化遺產，以「西湖十景」、湖光山色與豐富人文歷史聞名。

    第五天 : 7/23(星期四) 蔣村 -> 西溪天街

    1. 今天吃喝休息一天，在附近賣場跟商場逛逛。

    • 到處逛逛 。

      • 了解一下賣場跟商場賣些甚麼去了解一下。

    第六天 : 7/24(星期五) 蔣村 -> 法喜寺 -> 清河坊老街

    1. 今天搭地鐵加公交車去法喜寺與清河坊老街。

    • 法喜寺 。

      • 位於中國浙江省杭州市西湖群山中的上天竺法喜講寺（簡稱法喜寺），是杭州最著名且深受信徒與年輕人喜愛的千年古剎之一。它與中天竺法淨寺、下天竺法鏡寺並稱為「天竺三寺」，是極具代表性的觀音道場，也是海內外知名的白衣觀音起源地。

    • 清河坊老街 。

      • 位於中國浙江省杭州市上城區的清河坊歷史文化街區（簡稱清河坊老街或河坊街），是杭州目前唯一保存完好的舊城區歷史街巷。它坐落在吳山腳下，自南宋時期（西元1127年）便是京城最繁華的商賈雲集之地，見證了杭州「前朝後市」的千年繁華歷史。

    1. 今天要回家了，雖然還沒吃夠但也吃的開心逛得愉快，期待下一趟的旅程。

    • 蕭山國際機場 。

      • 飛飛飛回。
