## 影像測試方式 ( 以imatest 測試數據)
### 1. Visual ColorCheck reference (視覺色彩檢查參考)
在影像品質測試中，Visual ColorCheck reference（視覺色彩檢查參考）在 Imatest 中是透過「Color/Tone Interactive（或舊版 Colorcheck）」模組的視覺化色彩對比圖（Color Analysis / Visual Comparison Plot）來驗證。  
這項測試除了計算客觀色差數值外，核心功能在於將「相機實際拍攝的色塊顏色」與「標準參考顏色（Reference Colors）」並排（上下或內外框重疊）渲染在同一張視覺化對比圖上，讓工程師與品管人員能透過人眼直覺檢視色偏方向、飽和度增艷程度與記憶色（膚色、藍天、綠葉）的主觀視覺表現。  
以下是完整的測試架設、軟體操作與視覺化對比判讀步驟：  

1. 測試圖卡與參考基準（Reference）選擇
- 標準測試圖卡：
	- Calibrite / X-Rite ColorChecker Classic（24 色卡）：最標準的視覺色彩檢查參考卡，包含 6 個灰階與 18 個自然記憶色（如深淺膚色、藍天、綠葉、花朵等）。
	- ColorChecker SG（140 色卡） 或 eSFR ISO（內建色塊區）：適合需要更細膩膚色與廣色域視覺檢查的專案。
- 設定正確的 Reference 參考檔：
	- 在 Imatest 中必須根據色卡生產年份與光源選擇對應的標準 \(L^{*}a^{*}b^{*}\) 參考基準（例如 X-Rite default: post-Nov 2014 搭配 D50 或 D65 標準值）。
	- 若產品有特定「討好色（Preferred Color，例如手機人像刻意提亮膚色或拉高藍天飽和度）」需求，也可匯入自訂的 CSV 黃金參考檔（Golden Reference） 

2. 拍攝與環境架設關鍵
- 標準光源與均勻度：在標準燈箱（如 D65 日光、A 光源 2856K、CWF/TL84 螢光燈）下拍攝，確保色卡表面照明均勻度在 ±5% 以內，且無鏡面反光（Glare）。
- 控制色卡佔畫面比例：色卡寬度建議佔畫面寬度的 1/2 至 2/3（約 50%～70%），避免鏡頭邊角暗角（Vignetting）導致最外排色塊明度偏暗，造成視覺比對失真。
- 正確曝光：確保曝光誤差在 ±1/4 f-stop 以內，白色色塊不可過曝截斷（< 255 DN）。

3. Imatest 軟體操作步驟（以 Color/Tone Interactive 為例）
- 1. 開啟模組與匯入影像：啟動 Imatest 主程式，點擊 Color/Tone Interactive（若用舊版介面則為 Colorcheck），載入拍攝好的色卡影像。
- 2. 確認色卡規格與 Reference：
	- 在圖卡選單選擇對應型號（如 X-Rite ColorChecker 24）。
	- 在 Reference（參考標準） 欄位確認選擇與你色卡批次相符的標準值（或匯入自訂 Reference CSV）。
	- 在 Color space（色彩空間） 選擇影像對應的空間（一般消費性相機選 sRGB）。
- 3. 框選色塊 ROI：拖曳四個角點標記對齊色卡四角，確認 24 個偵測小方框皆精準落在各色塊中央安全區內。
- 4. 開啟視覺色彩對比圖（Color Analysis Plot）：
	- 在結果視窗右上角的 Display 下拉選單中，切換至 Color analysis（色彩分析圖）。
	- 介面會立即生成一張 24 宮格視覺對比陣列圖。

4. 核心視覺化圖表與數據判讀標準
在 Imatest 輸出的 Color analysis 視覺對比圖 中，每個格子都會同時顯示「標準參考色」與「相機實測色」的直覺對比：  

| 觀察維度 | 圖表呈現方式與視覺判讀重點 | 實務應用與合格參考 |
| ---- | ---- | ---- |
| 色塊並排/內外框視覺對比（Visual Patch Comparison） | 每個色塊格子中，上半部（或外框）為相機實測顏色，下半部（或內框）為理想 Reference 顏色，並標示對應的數值差異。 | 工程師可在校準過的螢幕上直接用肉眼檢視：兩者交界線是否幾乎無縫融合。若交界線明顯，代表該色系存在肉眼可見的色偏。 |
| 記憶色（Memory Colors）檢查 | 重點檢視圖卡第一排的 Dark Skin（深膚色）、Light Skin（淺膚色）、Blue Sky（藍天）、Foliage（綠葉） 這四個關鍵色塊。	 | 消費性手機與相機允許藍天與綠葉適度增艷（飽和度略高於 Reference），但膚色（Skin Tones）必須保持自然紅潤，嚴禁偏綠或偏蠟黃。 |
| 白平衡視覺偏移 | 觀察最底排 6 個中性灰階色塊（White to Black） 的上下半部顏色是否呈現純淨中性灰。 | 若灰階色塊實測區域明顯帶有洋紅（Magenta）或青綠色調，代表自動白平衡（AWB）在該光源下出現殘留色偏。 |
| 輔助量化指標驗證 | 搭配圖表上顯示的 Mean Chroma Saturation %（平均飽和度）、Δ E₀₀（總色差） 與 White Balance Error（白平衡誤差）。	 | 視覺檢查發現異常時，可透過數值精準定位是「明度曝光偏差（\(\Delta L^*\)）」還是「色相/飽和度偏差（\(\Delta C^*\)）」造成。 |

### 2. CIEDE2000 color error (色差)
在影像品質測試中，CIEDE2000 color error（Δ E₀₀ 色差）在 Imatest 中是透過「Color/Tone Interactive（互動式）」或「Color/Tone Auto（批次自動化）」模組來驗證（舊版為 Colorcheck 模組，官方建議新專案一律使用 Color/Tone）。  
CIEDE2000 是目前最貼近人眼視覺感知的色差標準，修正了傳統 CIE 1976（\(\Delta E^*_{ab}\)）在高飽和度區域與近中性灰區域的計算偏差。Imatest 會將拍攝到的色卡影像轉換至 CIELAB（\(L^{*}a^{*}b^{*}\)）色彩空間，並與標準色塊參考值比對，直接算出 Δ E₀₀ 與 Δ C₀₀。  
以下是完整的測試架設、軟體操作與數據判讀步驟：  

1. 測試圖卡與標準環境架設
- 推薦測試圖卡：
	- X-Rite / Calibrite ColorChecker Classic（24 色卡）：業界最通用的色彩還原測試卡。
	- ColorChecker SG（140 色卡）、IT8.7 或 eSFR ISO（內建色塊區）：適合需要更密集色域採樣或一圖多測的專案。
- 標準光源與照明條件（極度關鍵）：
	- 色卡參考值（Reference）是基於特定標準光源定義的（通常為 D50 或 D65，亦需驗證 A 光源 2856K 與 CWF 4150K 等不同色溫下的自動白平衡表現）。
	- 照明均勻度需在 ±5% 以內，使用雙燈以 30°～45° 角對稱照明，避免色卡表面產生鏡面反光（Glare）。
	- 圖卡佔畫面比例：建議色卡寬度佔畫面寬度的 1/2 至 2/3 即可；若塞滿全畫面，鏡頭邊角的漸暈（Vignetting）會導致邊緣色塊明度 \(L^{*}\) 偏低，拉高整體 Δ E₀₀ 誤差。
- 曝光控制：確保曝光誤差在 ±1/4 f-stop 以內（白色色塊不可過曝達到 255），避免明度偏差污染色差結果。

2. Imatest 軟體操作與驗證步驟（以 Color/Tone Interactive 為例）
- 1. 開啟模組：啟動 Imatest 主程式，點擊 Color/Tone Interactive（若需產線自動化批次測試則選 Color/Tone Auto）。
- 2. 選擇圖卡類型與參考檔：
	- 在圖卡選單中選擇對應規格（例如 X-Rite ColorChecker 24）。
	- 確認 Reference（參考值）與拍攝光源一致（例如 sRGB D65 或廠商提供的實測分光光度計 CGATS 參考檔）。
- 3. 匯入測試影像：點擊讀取檔案，載入拍攝好的色卡影像（支援 sRGB、Adobe RGB 等色彩空間設定）。
- 4. 確認色塊 ROI 框選：拖曳四個角點標記對齊色卡四角，確認 24 個偵測小方框皆精準落在每個色塊的中央安全區內（避開黑色邊框）。
- 5. 切換色差計算公式為 CIEDE2000：
	- 在設定視窗（Settings）或結果視窗的顯示選單中，將 Color error display 設定為 CIEDE2000（顯示為 Delta-E 00 / ΔE00）。
	- 在結果視窗右上角的 Display 下拉選單中，切換至 a*b* Color error 或 Color analysis 圖表。
- 6. 匯出定量報表：勾選輸出 CSV 或 JSON 報表，即可取得所有色塊的平均值、最大值以及個別色塊明細。

3. 核心數據指標與圖表判讀標準
在 Imatest 的分析圖表與 CSV 報表中，主要關注以下核心指標：  

| 指標名稱 | 物理意義與計算方式 | 業界判讀參考標準 |
| ---- | ---- | ---- |
| Mean Δ E₀₀（平均 CIEDE2000 色差） | 所有 24 個色塊（包含明度 $L^{*}$、彩度 $C^{*}$、色相 $H^{*}$ 差異）的整體平均色差。	| • < 1.0 ~ 20：人眼幾乎無法分辨差異（高階色彩校正/醫療/印刷級）。• 2.0 ~ 5.0：消費性相機與手機攝影的常見良好範圍（部分手機為討好人眼會刻意拉高飽和度，導致 Δ E₀₀ 落在 5 ~ 8）。• > 8.0 ~ 10.0：色彩明顯失真。 |
| Max Δ E₀₀（最大單一色塊色差） | 全圖卡中偏差最嚴重的單一色塊數值（常見於高飽和度的藍、紅或膚色塊）。 | 用於卡控單一顏色（例如特定品牌色、警示紅燈或人臉膚色）不發生嚴重偏色。 |
| Mean Δ C₀₀（純色度誤差，忽略明度） | 計算公式與 Δ E₀₀ 相同，但排除了明度差異（\(\Delta L^* = 0\)）。 | 極具實用價值：能排除環境光源亮度微幅波動或曝光誤差（AE 偏差）的干擾，純粹評估白平衡（AWB）與色彩矩陣（CCM）的色調準確度。 |
| Chroma Saturation %（平均飽和度百分比） | 實測彩度與標準彩度的比值百分比（100% 代表完全忠實還原）。 | 消費電子通常落在 100% ~ 115%（略微增艷）；安防與機器視覺通常要求貼近 95% ~ 105%。 |
### 進階調校功能：如果你測出來的 Δ E₀₀ 過高，可以直接點擊 Imatest Color/Tone 介面中的 Correction matrix（色彩校正矩陣 CCM） 按鈕，軟體會自動以最小化 Δ E₀₀ 為目標，幫你運算出最佳化的 3 × 3 CCM 矩陣參數供 ISP 工程師直接寫入韌體。

### 3. Excitation-filter blue or UV leakage(激發濾光片藍光或紫外光漏光)
在螢光成像系統（如生物醫療內視鏡、基因定序、AOI 螢光檢測）中，鏡頭前方會加裝發射濾光片（Emission Filter / Barrier Filter），目的是完全阻擋高強度的藍光或 UV 激發光（Excitation Light），只允許螢光訊號通過。一旦發生漏光（Leakage），感測器的背景黑電平（特別是 B 通道或全通道）就會被大幅墊高，直接拉低螢光對比度。  
以下是結合標準光學暗室架設與 Imatest 量化的完整驗證步驟：  

1. 測試環境與硬體架設（隔離螢光干擾是關鍵）

要精準測出「純粹的激發光漏光」，測試場域中絕對不能有任何會產生自發螢光（Autofluorescence）的材質：
- 使用無螢光漫反射標準白板（Non-fluorescent Diffuse Reflector）：
	- 首選材質：使用光學級 PTFE（鐵氟龍，如 Spectralon 高反射漫反射白板），其在 UV（250–400 nm）與藍光（400–500 nm）波段具備 > 95%～99% 的均勻漫反射率，且幾乎不產生自發螢光。
	- 嚴禁使用一般影印紙或普通色卡：普通白紙含有螢光增白劑（Optical Brighteners），照射 UV 或藍光會發出強烈藍色螢光，導致誤判為濾光片漏光。
- 全暗室環境與固定相機參數：
	- 在無環境雜散光的暗室中，開啟系統的 UV 或藍光激發光源均勻照射 PTFE 白板。
	- 鎖定相機參數：固定曝光時間（建議拉長至實際螢光拍攝的長曝光條件，以放大微弱漏光訊號）、固定增益（Gain / ISO），並關閉自動白平衡（AWB）與自動曝光（AE）。
	- 拍攝暗場基準圖（Dark Frame，必備）：關閉激發光源（在完全全黑下），以完全相同的曝光時間與增益拍攝一張全黑影像，作為感測器暗電流（Dark Current）扣除基準。

2. Imatest 軟體操作與量化分析步驟

根據測試目的，可選用以下任一 Imatest 模組進行量化：

### 方法 A：評估全畫面漏光分佈與邊角大角度漏光（使用 Uniformity 模組）

干涉型濾光片（Interference Filter）在廣角大入射角（AOI）下會發生藍移（Blue-shift），導致畫面邊角比中心更容易發生藍光/UV 漏光，因此最適合用 Uniformity 檢查：
- 1. 開啟模組：啟動 Imatest 主程式，點擊 Uniformity（舊版為 Flat Field）。
- 2. 載入影像與扣除暗場：
	- 載入「開啟 UV/藍光激發光源拍攝 PTFE 白板」的測試圖。
	- 在設定中匯入「關閉光源拍攝的 Dark Frame」進行背景暗電流扣除（若未扣除，暗電流會與漏光混在一起）。
- 3. 選擇線性設定（測 RAW 時）：若匯入線性 RAW 檔，勾選線性（Linear / Gamma = 1.0）。
- 4. 檢視 RGB 通道與等高線圖：勾選輸出 R, G, B Channels 與 2D/3D Contour Plot，觀察全畫面從中心到四個角落的殘餘亮度變化。

### 方法 B：多條件批次對比與 RGB 數值提取（使用 Color/Tone Interactive 模組）

若需精確比較不同曝光時間、不同濾光片批次或不同波長激發光下的漏光數值：
- 1. 建立自訂單一 ROI：開啟 Color/Tone Interactive，載入測試影像後，在畫面中央與四個角落手動框選 ROI（或使用簡易灰階/單塊圖卡定義）。
- 2. 提取各通道原始像素值（Pixel Level）：在結果視窗切換至 Pixel Level / RGB 數據表，記錄 R, G, B 三通道的平均 DN 值與標準差。

3. 核心數據判讀與漏光率計算標準
在 Imatest 產出數據後，主要透過以下三個維度判定濾光片阻隔（OD 值，Optical Density）是否合格：

| 判讀指標 | 計算與觀察方式 | 物理意義與合格標準 |
| ---- | ---- | ---- |
|淨漏光訊號強度（Net Leakage Signal） | $DN_{leak} = DN_{excitation} - DN_{dark} $	| 扣除感測器暗電流後的純漏光增量。理想阻隔下，$DN_{leak}$ 應趨近於 0（通常要求低於感測器讀出雜訊 Read Noise 的 1～2 倍以內）。 |
| B 通道異常抬升（Blue Channel Elevation） | 比較 Imatest 報表中的 B 通道與 R、G 通道數值 | 由於感測器對藍光（400–480 nm）以及部分無紅外截止的感測器對近紫外光（360–400 nm）在 B 通道的量子效率（QE）最高，一旦發生激發光洩漏，Imatest 會顯示 B 通道數值顯著高於 R 與 G 通道。 |
| 邊角大角度漏光比（Corner-to-Center Leakage） | 觀察 Uniformity 模組中的 Corner / Center 比率 | 若中心 DN_leak 接近 0，但四個角落的 B 通道數值明顯升高（呈現「中心黑、四角發藍」的反向漸暈），代表廣角大入射角導致發射濾光片截止波段偏移（AOI Blue-shift），需更換高入射角容忍度的濾光片。 |

進階估算濾光片實際阻隔率（OD 值）：  
若你有另一組「未加發射濾光片（或標準中性密度減光鏡 ND Filter 校正後）」在相同光源下的非飽和亮度基準 $DN_{unfiltered}$，即可透過以下公式驗證系統實際的截止光密度（Optical Density）：
$OD_{effective}$ = $ log_{10}\frac{DN_{unfiltered}}{DN_{leak}}$  
（一般螢光檢測系統通常要求激發波段的阻隔能力達到 OD 4 至 OD 6 以上，即漏光率低於 $(10^{-4})$ 至 $(10^{-6})$。）

### 4. Grayscale step chart(灰階階梯圖)
在影像品質測試中，Grayscale step chart（灰階階梯圖）在 Imatest 中主要是透過「Color/Tone Interactive（互動式）」或「Color/Tone Auto（批次自動化）」模組來進行分析（舊版為 Stepchart 模組，官方建議新專案一律優先使用功能更完整的 Color/Tone）。  
透過分析灰階階梯圖，可以一次驗證相機的 色調響應曲線（OECF / Gamma）、白平衡中性灰準確度、各階雜訊（Noise / SNR）、動態範圍（Dynamic Range）以及曝光誤差。  
以下是完整的測試架設、軟體操作與核心數據判讀流程：  

1. 常見灰階階梯圖卡與對應選項
不同排列方式的灰階圖卡，在 Imatest 中需選擇對應的圖卡類型（Chart Type）：
- 單行線性排列圖卡（Linear Stepcharts）：例如最經典的 Kodak / Tiffen Q-13（20 階）、Q-14 或 Stouffer T2115 / T4110。在 Color/Tone 中應選擇 Grayscale stepchart (linear)。
- 多行或環形排列圖卡（Multi-row / Circular Stepcharts）：例如 ISO 14524（20 階環形 OECF 圖卡）、ISO 15739、ITE 灰階卡 或 Imatest 36 階透射式動態範圍卡。在 Color/Tone 中應選擇 Multi-row Grayscale charts 並指定具體型號。

2. 拍攝與取樣關鍵（確保數據準確）
- 圖卡佔畫面寬度不超過 2/3（重要）：拍攝時不要讓灰階卡填滿整個畫面（建議圖卡寬度控制在畫面寬度的 1/2 ~ 2/3 以內），以避免鏡頭邊緣的「暗角衰減（Light Falloff）」造成兩端色塊亮度失真。
- 照明均勻度（±5% 以內）：使用雙燈以 30°～45° 角對稱照明反射式圖卡（避免正面反光 Glare）；若使用透射式灰階卡，需將燈箱周圍未被圖卡覆蓋的區域用黑布或黑卡完全遮蔽，防止雜散光（Veiling Glare）抬高暗部數值。
- 避免亮暗部截斷（Clipping）：調整曝光時間，讓最亮的第一階白塊接近飽和但未過曝（8-bit 影像約 235 ~ 245 DN，不可達到 255），最暗階也應保留微弱訊號（> 0 DN）。
- 微幅失焦（Optional，針對印刷網點卡）：若使用印刷網點製成的灰階卡，可將鏡頭極輕微失焦，避免印刷紙張紋理被誤算為感測器雜訊。


3. Imatest 軟體操作與驗證步驟（以 Color/Tone Interactive 為例）

- 1. 開啟模組：啟動 Imatest 主程式，點擊 Color/Tone Interactive（若需大量自動化產線測試則選 Color/Tone Auto）。
- 2. 設定圖卡類型與參考檔：
	- 在右側 Chart 下拉選單中，選擇對應的灰階圖卡類型（如線性階梯圖或多行灰階圖）。
	- 在 Reference 欄位確認標準光密度（Optical Density）或反射率參考值（例如 Q-13 標準密度增量為每階 0.10 D；若為透射式 36 階卡則需匯入原廠附帶的校正檔）。
- 3. 匯入影像：點擊 Read image file 載入測試影像（建議同時選取 2 張同條件連拍影像，可一併計算純時間雜訊 Temporal Noise）。
- 4. 確認 ROI 框選：拖曳四個角點標記框住整個灰階區域，進入微調視窗後確認每個小方框都精準落在各灰階色塊的中央（避開色塊邊界線）。
- 5. 檢視分析圖表：在結果視窗右上角的 Display 選單中切換檢視不同維度的圖表，並可匯出 CSV 或 JSON 報表。

4. 核心數據指標與圖表判讀標準

透過灰階階梯圖分析，主要判讀以下四項核心影像品質指標：

| 檢視項目 / 圖表名稱 | 核心指標與物理意義 | 業界判讀標準 |
| ---- | ---- | ---- |
| Tonal Response / OECF（色調響應與伽馬曲線） | 繪製「輸入光密度 / 曝光量（Log Exposure）」與「輸出像素值（Pixel Level）」的關係曲線，計算系統平均 Gamma（伽馬值） 與 Exposure Error（曝光誤差，單位 f-stops）。	 | • 標準 sRGB 輸出：系統平均 Gamma 通常落在 0.45 ~ 0.55（對應顯示端 2.2 校正）。• 曝光誤差：一般要求控制在 ±0.25 ~ ±0.5 EV 以內。 |
| White Balance / Gray Balance（灰階白平衡誤差） | 檢視 R、G、B 三條色調曲線是否重疊，並量化各灰階色塊的色度偏移 Δ C 或 Δ E。 | 理想狀況下 R、G、B 三線完全重合；中灰階的白平衡色偏通常要求 Δ C < 2 ~ 3。 |
| Noise & SNR（各灰階雜訊與信噪比） | 計算每一個灰階色塊的 RMS Noise 與 SNR (dB)。 | 標準照度下中灰階（18% Gray）通常要求 SNR > 35 dB；暗部灰階常以 SNR = 20 dB 作為細節可用下限。 |
| Dynamic Range（動態範圍） | 依據暗部達到不同 SNR 門檻（SNR = 10, 4, 2, 1）計算有效亮度跨度（單位：f-stops 或 dB）。 | 一般反射式圖卡（如 Q-13）密度跨度約 2.0 D（約 6.5 stops），僅能測出動態範圍下限；高動態範圍需改用 36 階透射式階梯圖。 |

### 5. SNR at gray levels (灰階信噪比)
在影像品質測試中，SNR at gray levels（灰階信噪比）在 Imatest 中主要是透過「Color/Tone（Multicharts / Multitest）」或「Stepchart（灰階卡）」模組，量測測試圖卡上不同亮度灰階色塊（Gray Patches）的訊號平均值與像素標準差（雜訊）之比值。  
透過測量從亮到暗各個灰階的 SNR（單位通常為 dB 或比率），可以精準評估相機在亮部、中灰（18% Gray）到暗部陰影區的畫質純淨度與降噪（NR）演算法表現。  
以下是完整的測試驗證流程與核心判讀步驟：  

1. 測試圖卡與分析模組選擇
要量測不同灰階的信噪比，畫面中必須包含多個已知反射率或光密度的中性灰階區塊：
- 常用測試圖卡：
	- 24 色卡（X-Rite / Calibrite ColorChecker）：最普及的日常測試圖卡，其最底排包含 6 個標準中性灰階區塊（從白到黑，含 18% 中灰）。
	- 多階灰階卡（OECF / Stepchart）：如 ISO 14524 20 階灰階卡、Kodak Q-13/Q-14 灰階卡，或透射式 36 階灰階卡，能提供更細膩的亮暗部灰階採樣。
	- 綜合圖卡（eSFR ISO / SFRplus）：內建多階灰階區塊，可在一張圖內同時測解析度與灰階 SNR。
- 對應 Imatest 模組：使用 Color/Tone Interactive（手動框選與即時檢視圖表）或 Color/Tone Auto（自動化批次測試與產出報表）。

2. 拍攝與取樣關鍵（確保數據準確）
- 均勻照明（核心前提）：確保測試圖卡表面的光照度均勻（建議均勻度 > 95%），避免燈光反光（Glare）或光源不均導致同一灰階區塊內產生亮度梯度，被誤判為高雜訊。
- 避免亮暗部截斷（Clipping）：調整曝光時間或光源亮度，讓最亮的白色色塊接近飽和但未過曝（8-bit 影像約 235 ~ 245 DN，不可達到 255）；最暗的黑色色塊也應保留微弱訊號（> 0 DN）。
- 連拍 2 張以上（強烈建議）：
	- 單張影像測得的是「總雜訊（包含空間固定模式雜訊 FPN 與隨機時間雜訊 Temporal Noise）」。
	- 若在相同條件下連續拍攝 2 張影像並一併匯入 Imatest，軟體可透過雙圖相減法精準分離出純粹的 Temporal SNR（時間信噪比），這是業界評估感測器與 ISP 降噪表現的標準做法。

3. Imatest 軟體操作步驟（以 Color/Tone Interactive 為例）
- 1. 開啟模組：啟動 Imatest 主程式，點擊 Color/Tone Interactive。
- 2. 選擇圖卡類型並匯入影像：
	- 在左側或上方選單選擇對應的圖卡規格（例如 X-Rite ColorChecker 24 或 OECF 20-patch）。
	- 載入拍攝好的測試影像（若要測 Temporal SNR，請同時選取 2 張同條件連拍影像）。
- 3. 確認灰階 ROI 框選：拖曳四個角點標記，確保偵測框精準落在各個灰階色塊的中央安全區內（避開色塊邊緣交界處）。
- 4. 開啟 Noise & SNR 分析圖表：
	- 在結果視窗右上角的顯示選單（Display）中，切換至 Noise & SNR（或 SNR (dB)）。
	- 勾選顯示各通道（R, G, B, Y 亮度）的 SNR 曲線與數值表。
- 5. 匯出定量數據：點擊匯出 CSV 或 JSON 報表，即可直接提取每一個灰階色塊對應的亮度值（Pixel Level / Exposure）與精確 SNR 數值。


4. 核心數據與圖表判讀標準

在 Imatest 的 Noise & SNR 結果圖 中，橫軸代表「灰階色塊編號或相對曝光量（從暗到亮）」，縱軸代表 SNR (dB)
（計算公式：$SNR_{dB}$ = $20log_{10}(Signal / Noise)$：  

| 觀察指標 | 物理意義與業界參考標準 |
| ---- | ---- |
| Y (Luminance) SNR (dB) | 最核心的整體亮度信噪比（依據人眼對亮度敏感度加權計算 Y = 0.2126R + 0.7152G + 0.0722B）。1. 亮部與中灰階（18% Gray）：消費性電子與安防鏡頭在標準照度下通常要求 > 35 dB ~ 40 dB（畫質極為純淨）。2. 暗部灰階（Dark Gray）：隨亮度降低 SNR 會自然下降，業界常以 SNR = 20 dB（訊雜比 10:1） 作為暗部細節仍清晰可用的評估門檻。 |
| R / G / B 各通道 SNR	| 分別檢視紅、綠、藍三通道的信噪比。若在低色溫（如 2800K 黃光）下測試，藍色通道（B） 因為數位增益放大較多，其 SNR 曲線通常會明顯低於綠色與紅色通道，可用來判斷白平衡增益是否過度放大雜訊。 |
| Temporal SNR vs. Total SNR | 若使用雙圖分析，可同時比對純時間雜訊計算的 SNR 與單圖空間雜訊計算的 SNR；若兩者落差過大，代表圖卡照明不均或感測器存在固定模式雜訊（FPN）。 |
### 實務判讀提醒：在測試 JPEG / YUV 影像時，部分相機的 ISP 會對中暗部施加強烈的邊緣保留降噪（2D/3D NR），導致曲線在特定暗灰階出現「異常平坦或反升」的現象；此時建議同步檢查 eSFR ISO / Color/Tone 的紋理銳利度（Texture Acutance），確認高 SNR 不是靠「過度塗抹細節」換來的。
### 6. Dynamic range (動態範圍)
在影像品質測試中，Dynamic range（動態範圍）在 Imatest 中主要是透過分析「多階灰階測試卡（Stepchart）」的光電轉換函數（OECF）與各灰階區塊的訊號雜訊比（SNR），計算從「最亮飽和點」到「暗部達到特定 SNR 門檻」之間所能涵蓋的亮度跨度。  
根據你手邊擁有的測試圖卡與相機動態範圍高低，主要有以下三種標準驗證方式：  

1. 測試圖卡與對應模組選擇
普通反射式圖卡（如一般 24 色卡）的對比度上限僅約 100:1（約 6.5 檔光圈 / 40 dB），遠低於現代感光元件的動態範圍。因此必須依據產品等級選擇正確的方案：

| 測試方案 | 適用場景 | 推薦測試圖卡 | 對應 Imatest 模組 |
| ---- | ---- | ---- | ---- |
| 單張透射式測法（最標準、最準確） | 一般相機、手機、安防與車載 HDR 鏡頭（可測 50–150 dB） | 透射式 36 階動態範圍卡
（如 Imatest 36-Patch DR Chart 或 Xyla 燈箱） | Color/Tone Interactive 或 Color/Tone Auto（舊版為 Stepchart） |
| 高對比解析度測法（專測強力 Tone Mapping / HDR） | 啟用多幀合成或局部色調映射（Local Tone Mapping）的手機與車載相機 | Contrast Resolution Chart
（內含不同對比度小方塊，範圍達 100 dB） | Color/Tone（Contrast Resolution 模式） |
| 多張不同曝光合併法（無高階透射圖卡時的替代方案） | 僅有普通反射式灰階卡（如 Q-13、24 色卡），且相機可手動調整曝光 | 反射式灰階卡（拍攝 2～4 張間隔 2～4 EV 的照片，不適用於 HDR 模式） | Color/Tone 匯出 CSV 後，丟入 Dynamic Range 後處理器 |


2. 拍攝與環境架設關鍵（避免眩光污染數據）
動態範圍測試最大的天敵是鏡頭內部反射造成的雜散光（Veiling Glare / Flare），它會抬高暗部亮度，導致測出來的動態範圍大幅縮水：  
- 暗室環境與遮光罩：必須在完全無環境光的暗室中拍攝；透射式圖卡四周未被圖卡覆蓋的燈箱白光區域，務必使用全黑不透光遮光板（Shroud / Mask）完全遮蔽。
- 精準控制曝光（不允許大量過曝）：調整相機曝光時間或燈箱亮度，讓最亮的第 1 階（最白塊）剛好接近飽和但未完全截斷（建議最多僅允許 1～2 個最亮色塊過曝），才能測出完整的動態範圍上限。
- 設定最低原生 ISO：測試感測器最大動態範圍時，應將增益固定在相機的最低原生 ISO（Base ISO）。


3. Imatest 軟體操作步驟（以單張 36 階透射卡 + Color/Tone 為例）

- 1. 開啟模組：啟動 Imatest 主程式，點擊 Color/Tone Interactive（批次測試可用 Color/Tone Auto）。
- 2. 匯入測試影像與圖卡定義檔：
	- 載入拍攝好的 36 階動態範圍測試圖（建議同時拍 2 張同條件影像並勾選多圖分析，可更精準分離時間雜訊）。
	- 在圖卡類型中選擇對應的 36-patch Dynamic Range（需確保已匯入該圖卡原廠附帶的光密度校正檔 Density Reference File，否則光密度範圍會不準確）。
- 3. 確認 ROI 框選：調整四個角點標記，確保 36 個灰階方塊皆精準落在偵測框內（避開方塊邊緣交界處）。
- 4. 檢視動態範圍圖表：
	- 在結果視窗右上角的顯示選單（Display）中，切換至 Tonal Response（色調響應） 或 Noise & SNR。
	- 勾選顯示 Dynamic Range（動態範圍） 標示線。

4. 核心數據與單位判讀標準
在 Imatest Tonal Response 結果圖 中，動態範圍會同時以 f-stops（光圈檔數 / EV） 與 dB（分貝，1 stop ≈ 6.02 dB） 呈現，並依據「暗部可接受的最低訊號雜訊比（Scene-referenced SNR）」分為四個品質等級：  

| 品質等級 | 對應 SNR 門檻 | 物理意義與業界判讀標準 |
| ---- | ---- | ---- |
| High（高品質） | SNR = 10 (20 dB)	| 畫面純淨、無明顯噪點的可用動態範圍。商業攝影與高階影像系統最常採用的嚴格評估標準。 |
| Medium-High（中高） | SNR = 4 (12 dB)	| 暗部有輕微噪點但細節仍清晰可辨。 |
| Medium（中品質） | SNR = 2 (6 dB) | 噪點已明顯可見，接近一般視覺判讀的可用下限。 |
| Low（極限值） | SNR = 1 (0 dB) | 理論極限動態範圍（訊號強度等於雜訊底噪，暗部幾乎被雜訊淹沒）。感測器廠商規格書標示的「最大動態範圍（如 120 dB / 14 stops）」通常是指此數值（或基於 RAW 檔計算）。 |

### 實務判讀提醒：
- 若你測試的是 JPEG / YUV，ISP 的降噪演算法（NR）會壓低暗部雜訊，使測出的動態範圍數值（特別是 SNR = 1 與 SNR = 10）看起來比 RAW 檔更高，此時建議搭配觀察圖表中的 Slope（局部伽馬斜率），確認暗部細節沒有被抹平。

### 7. Uniform-field vignetting(均勻場漸暈)
在影像品質測試中，Uniform-field vignetting（均勻場漸暈 / 暗角）在 Imatest 中與「中心到邊緣衰減（Center-to-edge falloff）」相同，皆是透過「Uniformity（舊版稱 Flat Field，平面場）」模組來進行量化驗證。  
其核心測試原理是拍攝一張亮度完全均勻的純白或中灰平面（Uniform Field），並量化「畫面四個角落」與「畫面中心最亮處」的相對亮度比率（Relative Illumination）以及邊角的色彩偏移（Color Shading）。  
以下是完整的測試驗證流程與判讀標準：  

1. 測試設備與拍攝關鍵（排除外部光源干擾）
均勻場測試對光源均勻性要求極高，光源本身的亮度不均會直接計入漸暈誤差中：
- 標準光源選擇：
    - 積分球（Integrating Sphere）：最推薦的標準設備。將鏡頭貼近積分球開口並完全填滿視角（FOV），可提供均勻度 > 98%～99% 的理想光源，特別適合廣角與魚眼鏡頭。
    - 專業級均勻背光燈箱（Uniform Light Box）：若無積分球，可使用校正級均勻燈箱，確保發光面完全覆蓋相機視野且無環境雜散光反射。
- 曝光與影像設定：
    - 控制中心亮度在 50%～80% 飽和度：針對 8-bit 影像，畫面中心最亮處的像素值（DN）應控制在 128 ~ 204 之間。嚴禁中心過曝達到 255（Clipping），否則會低估實際的漸暈程度。
    - 拍攝暗場影像（Dark Frame，測 RAW 時必備）：蓋上鏡頭蓋在相同快門與增益下拍一張全黑圖，供 Imatest 扣除感測器黑電平（Black Level）與暗電流偏移。
    - 區分 RAW 與 ISP 輸出（JPEG/YUV）：
	    - 測 RAW 檔：驗證鏡頭本身真實的光學漸暈（Optical & Mechanical Vignetting）與感測器主光線角度（CRA）不匹配造成的衰減。
		- 測 JPEG / YUV：驗證經過 ISP 鏡頭陰影校正（LSC, Lens Shading Correction） 補償後的最終殘留暗角。

2. Imatest 軟體操作與驗證步驟
- 1. 開啟模組：啟動 Imatest 主程式，點擊 Uniformity（舊版介面為 Flat Field）。
- 2. 匯入影像：載入拍攝好的均勻場測試影像；若有拍攝 Dark Frame，可在設定視窗中一併指定扣除。
- 3. 設定色彩空間與線性度（Gamma）：
	- 若分析線性 RAW 檔，需在設定中勾選線性（Linear / Gamma = 1.0），確保計算出真實物理光強度的漸暈比率。
	- 若分析標準 sRGB JPEG/YUV，則維持預設 Gamma（約 2.2）或勾選線性化計算相對照度。
- 4. 勾選輸出圖表：勾選 Luminance（亮度均勻度）、Color Shading（色彩陰影） 與 2D/3D Contour Plot（等高線圖）。
- 5. 執行分析與匯出數據：檢視分析結果視窗，並可匯出 CSV 或 JSON 報表取得各區域精確數值。

3. 核心數據指標與圖表判讀標準
在 Imatest Uniformity 結果報告 中，主要透過以下指標判定漸暈程度：

| 指標名稱 | 單位 | 物理意義與業界參考標準 |
| ---- | ---- | ---- |
Worst Corner / Maximum
| （最差邊角亮度比） | %（百分比） | 評估漸暈（Vignetting）最關鍵的指標。計算四個角落中最暗角落與中心最大亮度的百分比（或換算為衰減量 100% - 該數值）。1. ISP 校正後（JPEG）：消費性電子與車載影像通常要求 > 70% ~ 80%（即邊角漸暈不超過 20%～30%）。2. 未校正光學 RAW：視鏡頭設計而定，標準鏡頭約 50% ~ 70%，廣角鏡頭約 30% ~ 50%。 |
| Mean Corner / Maximum（四角落平均亮度比）	| %（百分比） | 四個角落平均亮度與最大亮度的比值。若四個角落數值彼此落差過大，代表鏡頭組裝存在光軸偏心（Decentering）或遮光罩干涉。 |
| Edge / Maximum（四邊邊緣亮度比） | %（百分比） | 畫面上下左右四邊中點相對於中心最大亮度的百分比。 |
| Color Shading (R/G, B/G)	| %	 | 彩色漸暈（Color Vignetting）。因不同波長光線在邊角產生不同衰減，導致畫面中心偏綠、邊角偏紅或偏藍。Imatest 會量化邊角 R/G 與 B/G 相對於中心的偏移率，一般要求控制在 ±5% ~ ±10% 以內。 |
### 圖形化快速判斷：觀察輸出的 Luminance Contour（亮度等高線圖），正常的鏡頭漸暈應呈現「以畫面中心為圓心的同心圓平滑遞減」；若等高線出現不對稱歪斜或最亮點嚴重偏離幾何中心，則表示光學機構組裝存在偏心瑕疵。

### 8. Center-to-edge falloff(中心到邊緣的衰減)
在影像品質測試中，Center-to-edge falloff（中心到邊緣的衰減，光學與影像測試領域正式稱為 Relative Illumination 相對照度 或 Lens Shading 鏡頭陰影 / Vignetting 暗角）在 Imatest 中是透過「Uniformity（均勻度 / Flat Field 平面場）」模組來進行量化驗證。  
此測試的核心邏輯是拍攝一張亮度完全均勻的純白或中灰平面（Flat Field），並比較「畫面最暗邊角」與「畫面最亮中心」的亮度百分比與色彩偏移。  
以下是完整的測試設備準備、Imatest 操作流程與核心數據判讀標準：  

1. 測試設備與拍攝關鍵（確保數據準確）
均勻度測試對光源均勻性極為敏感，若光源本身不均勻，會直接污染鏡頭衰減的量測結果：
- 均勻光源設備（二選一）：
    - 積分球（Integrating Sphere）：最推薦的標準設備。將鏡頭直接對準積分球開口（建議貼近開口以填滿整個 FOV，特別是廣角鏡頭），可提供均勻度 > 98%～99% 的理想光源。
    - 高均勻度背光燈箱（Uniform Light Box / Transmissive Diffuser）：若無積分球，可使用專業校正級燈箱，確保燈箱發光面積遠大於鏡頭視角（FOV）。
- 曝光與影像設定：
    - 避免過曝或欠曝：將影像中心（最亮處）的像素值（Pixel Level）控制在 50% 至 80% 飽和度之間（針對 8-bit 影像約 128 ~ 204 DN）。若中心過曝達到 255（Clipping），會導致計算出的邊緣衰減率失真（看起來變小）。
    - 拍攝暗場對照（Dark Frame，測 RAW 時強烈建議）：蓋上鏡頭蓋在相同曝光時間與增益下拍攝一張全黑影像，用於扣除感測器暗電流基底（Black Level）。
    - 區分 RAW 與 ISP 輸出（JPEG/YUV）：
	    -  測 RAW 檔：驗證鏡頭本身真實的光學漸暈（Vignetting）與感測器微透鏡（CRA）衰減。
	    - 測 JPEG / YUV：驗證經過 ISP 鏡頭陰影校正（LSC, Lens Shading Correction） 演算法補償後的最終殘留暗角。

2. Imatest 軟體操作與驗證步驟

- 1. 開啟模組：啟動 Imatest 主程式，點擊 Uniformity（舊版介面稱為 Flat Field）。
- 2. 匯入測試影像：選擇拍攝好的均勻平面影像（若有拍攝 Dark Frame，可在設定中一併匯入進行背景扣除）。
- 3. 選擇分析與輸出圖表：
    - 在設定視窗（Settings）中，確認選擇正確的 Gamma / Color Space（若匯入線性 RAW 檔需勾選線性設定；一般 sRGB JPEG 則維持預設 Gamma ≈ 2.2）。
    - 勾選顯示 Luminance（亮度均勻度）、Color Shading（色彩陰影） 與 3D Contour Plot（3D 等高線圖）。
- 4. 執行分析與匯出報表：點擊分析後，可查看全畫面 2D/3D 亮度分佈圖，並匯出 CSV 或 JSON 報表取得精確的角落數值。


3. 核心數據指標判讀標準
在 Imatest Uniformity 結果報告 中，主要觀察以下指標來評估 Center-to-edge falloff：  

| 指標名稱 | 單位 | 物理意義與判讀標準 |
| ---- | ---- | ---- |
| Worst Corner / Maximum（最差邊角相對亮度） |　%（百分比） | 最核心的 Center-to-edge falloff 指標。計算四個角落中「最暗角落的亮度」除以「畫面最亮處（通常為中心）的亮度」之百分比。1. 經 ISP 校正後（JPEG）：一般消費級與安防鏡頭通常要求 > 70% ~ 80%（即衰減不超過 20%～30%）。2. 未校正光學 RAW：視鏡頭廣角程度而定，一般鏡頭約 50% ~ 70%，超廣角鏡頭可能低至 30% ~ 50%。 |
| Mean Corner / Maximum（四角落平均相對亮度） | %（百分比） | 四個角落亮度的平均值與最大亮度的比值，可用來判斷鏡頭組裝是否存在偏心（Decentering，若四角落數值差異過大代表光軸偏移）。 |
| Edge / Maximum（四邊邊緣相對亮度） | %（百分比） | 畫面上下左右四邊中點（1.0 Field 水平/垂直邊界）相對於中心的亮度百分比。 |
| Color Shading (R/G, B/G) | % 或 Δ C | 色彩衰減（Color Falloff）。當不同波長光線在邊角產生不同程度的衰減時，會導致畫面中心偏綠、邊角偏紅或偏藍（常見於大角度入射感測器）。Imatest 會計算 R/G 與 B/G 在邊角相對於中心的偏移百分比，一般要求控制在 ±5% ~ ±10% 以內。 |
### **圖形化快速檢查**：在 Imatest 輸出的 Luminance Contour（亮度等高線圖） 中，理想的鏡頭衰減應該呈現「以畫面正中心為圓心的同心圓狀平滑遞減」。如果最亮點明顯偏離畫面幾何中心，則代表鏡頭或感光元件存在組裝對位偏差。

### 9. Corner color-edge shift(邊角顏色偏移)
在影像品質測試中，Corner color-edge shift（邊角彩色邊緣偏移，即橫向色差 Lateral Chromatic Aberration, LCA / Color Fringing）在 Imatest 中主要是透過分析影像邊緣區域的「斜邊（Slanted-edge）」來進行驗證。
1. 準備測試圖卡與模組選擇
要測量邊角的 RGB 通道偏移，必須在影像四周與四個角落配置高對比的斜邊，並使用支援斜邊分析的自動化模組：  
    - 推薦圖卡與模組：使用 SFRplus、eSFR ISO 或 Checkerboard（棋盤格）。這些模組能自動偵測影像角落的感興趣區域（ROI）並批次產出全畫面數據。
    - 單點手動測試：若使用傳統圖卡或自訂標靶，可使用基礎的 SFR 模組手動框選角落邊緣。

2. 拍攝與取樣關鍵（確保數據準確）
    - ROI 位置要求：必須選取距離影像中心 30% 至 100%（最外圍邊角） 之間的斜邊。若距離中心小於 30%，色差現象不明顯，Imatest 會將數據反灰或省略。
    - 邊緣方向（切線方向為佳）：橫向色差是沿著「影像中心往外輻射的徑向（Radial）」產生的。因此，測試邊緣必須盡量與徑向垂直，也就是切線方向（Tangential）的邊緣（例如畫面左右兩側的近垂直邊緣、上下兩側的近水平邊緣）。若選到徑向邊緣，則無法觀測到 color-edge shift。
    - 影像格式考量：
        - RAW 檔（未經 ISP 處理）：能測出鏡頭最真實的光學物理偏移。
        - JPEG / YUV（經過 ISP 處理）：通常已被演算法（如色差校正 CAC 或去馬賽克）修正過，測出來的數值代表「終端成像的殘留色邊表現」。

3. Imatest 軟體操作與驗證步驟
以最常用的 SFRplus 或 Rescharts 介面為例：
- 1. 匯入影像：開啟 Imatest 主程式，點擊對應模組（如 SFRplus 或 Rescharts）並載入拍攝好的測試圖。
- 2. 確認角落 ROI：確認軟體自動框選的區域已涵蓋四個角落（Corners）與四邊邊緣（Edges）的切線斜邊。
- 3. 開啟色差分析圖表：
    - 在分析設定（Settings）或輸出圖表選項（Plot options）中，勾選 Chromatic Aberration（色差） 相關圖表。
    - 若使用單一 SFR 模組，執行分析後在結果視窗的顯示下拉選單中切換至 Chromatic Aberration。
- 4. 匯出數據：可勾選輸出 CSV 或 JSON 報表，直接提取各個角落 ROI 的定量數值。

4. 核心數據指標判讀
在 Imatest 色差結果圖表（SFR CA Plot） 中，主要觀察以下三個指標來判定是否合格：

| 指標名稱 | 單位 | 物理意義與判讀標準 |
| ---- | ---- | ---- |
| CA (area) | Pixels（像素） | 肉眼可見的色邊嚴重程度。計算 R、G、B 三條正規化邊緣曲線（最高與最低振幅曲線）之間的積分面積。此數值越接近 0 越好；一般消費級鏡頭在邊角通常要求 < 1.0 ~ 1.5 pixels（視產品規格而定）。 |
| CA (crossing) | Pixels（像素） | 純鏡頭光學邊緣中心偏移量。計算各色通道曲線通過振幅 0.5（邊緣正中心）時的像素距離差，較不受 ISP 銳化或去馬賽克變形的干擾。 |
| R-G / B-G	% | （百分比） | 紅綠 / 藍綠通道的相對位置偏移比例（以「中心到該 ROI 的距離」為分母）。此數據通常提供給 ISP 工程師，作為寫入橫向色差校正（CAC）演算法參數的依據。 |

### 圖形化直覺檢查：在 CA Plot 中，你可以直接看到紅（R）、綠（G）、藍（B）三條邊緣響應曲線（Edge Profile）的分離程度。若三條線在角落幾乎重疊，代表沒有 color-edge shift；若紅線與藍線明顯向左右錯開（產生洋紅色區塊），即代表存在明顯的邊角彩邊偏移。

### 10. Lateral chromatic shift(橫向色移)
在影像品質測試中，Lateral chromatic shift（橫向色差 / 橫向色偏，又稱 Lateral Chromatic Aberration, LCA）在 Imatest 中是透過「斜邊法（Slanted-edge）」來量化 R、G、B 三個色彩通道在空間位置上的偏移量。
這項測試不需要獨立的特殊演算法，而是直接整合在 Imatest 的解析度（MTF/SFR）分析模組中。以下是具體的測試驗證流程與判讀方法：
1. 選擇測試圖卡與對應模組
為了同時評估畫面中心到邊緣（特別是四個角落）的色偏程度，需使用具備多個斜邊的測試圖卡：
    - 全畫面自動化分析（最推薦）：使用 SFRplus、eSFR ISO 或 Checkerboard（棋盤格） 模組。軟體會自動偵測全畫面（包含邊緣與四角）的感興趣區域（ROI）並批次產出橫向色差數據。
    - 廣角 / 特殊視角鏡頭：使用 SFRreg 模組，可自由在視野最外圍放置多個獨立的斜邊標靶進行偵測。
    - 單點局部測試：使用一般傳統斜邊圖卡搭配基礎的 SFR 模組，手動框選畫面邊緣的斜邊進行分析。
2. 拍攝與取樣關鍵（確保測得有效數據）
進行 Lateral chromatic shift 測試時，取樣方向與位置是成敗關鍵：
    - 必須選取「切線方向（Tangential）」邊緣：橫向色差是從影像中心向外輻射產生的（放大倍率隨波長不同而改變）。因此，必須選取與半徑垂直（切線方向）的斜邊（例如畫面左右兩側的「近垂直邊緣」、上下兩側的「近水平邊緣」）。若選到徑向（Radial）邊緣，色偏會沿著邊緣方向重疊，導致測不到偏移。
    - ROI 距離中心需大於 30%：所選的斜邊必須位於距離影像中心 30% 至 100%（邊角處） 的區域。距離中心小於 30% 時色偏極微弱，Imatest 會自動將該 ROI 的色差數據反灰或略過。
    - 避免亮暗部截斷（Clipping）：確保白色區塊未過曝（< 255）、黑色區塊未死黑（> 0），否則邊緣曲線失真會導致通道位移計算錯誤。
    - 區分 RAW 與 ISP 輸出（JPEG/YUV）：
        - 測 RAW 檔：評估鏡頭本身真實的光學色散偏移。
        - 測 JPEG / YUV：評估經過 ISP 橫向色差校正（CAC） 演算法修正後的最終殘留色偏。

3. Imatest 軟體操作步驟
以最常用的 Rescharts（SFRplus / eSFR ISO / Checkerboard） 介面為例：
- 1. 載入影像：開啟 Imatest 主程式，點擊對應模組並匯入拍攝好的測試影像。
- 2. 確認 ROI 框選：檢查自動偵測的紅框（ROI）是否已正確涵蓋四個角落（Corners）與四邊邊緣的切線斜邊。
- 3. 開啟色差分析圖表：
    - 在分析設定（Settings）或輸出選項中，勾選 Chromatic Aberration（色差） 相關圖表。
    - 若使用單一 SFR 模組，執行分析後在結果視窗的顯示下拉選單中切換至 Chromatic Aberration。
- 4. 檢視全畫面統計或匯出數據：在 Multi-ROI 檢視模式下，可直接查看邊角區（Cor）的色偏平均值與最大值，或勾選輸出 CSV / JSON 報表進行自動化比對。

4. 核心數據與圖表判讀標準
在 Imatest 的 Chromatic Aberration 結果圖（CA Plot） 中，主要判讀以下指標：

| 指標名稱 | 單位 | 物理意義與業界參考標準 |
| ---- | ---- | ---- |
| CA (area) | Pixels（像素） | 肉眼可見的彩邊嚴重程度。計算 R、G、B 三條正規化邊緣曲線（最高與最低曲線）之間的包圍面積（圖中洋紅色區塊）。一般消費級鏡頭在邊角通常要求 < 1.0 ~ 1.5 pixels。 |
| CA (area) % | %（百分比）| 相對偏移比例（以「中心到該 ROI 的距離」為分母），較不受感光元件畫素高低影響。Imatest 官方參考標準：< 0.04%：極輕微（肉眼幾乎無感）0.04% – 0.08%：輕微 0.08% – 0.15%：中等 > 0.15%：嚴重 |
| CA (crossing)	| Pixels（像素） | 純光學邊緣中心偏移量。測量各色通道曲線通過振幅 0.5（邊緣正中心）時的像素距離差，較不受 ISP 銳化或去馬賽克演算法的干擾。 |
| R-G / B-G	| Pixels 或 % | 明確顯示紅綠（R-G）與藍綠（B-G）通道各自的偏移量與方向（正負號），常用於提供給 ISP 工程師調整校正參數。 |
### 圖形化快速判斷：在結果圖中觀察紅（R）、綠（G）、藍（B）三條邊緣響應曲線。若三條線在邊角緊密重疊，代表沒有 Lateral chromatic shift；若紅線與藍線明顯向左右錯開（中間產生寬大的洋紅色區塊），即代表存在明顯的橫向色偏。

### 11. Rolling-shutter line skew(捲簾窗線傾斜)


### 12. Rolling-shutter distortion ratio(滾動快門畸變率)
在影像品質測試中，Imatest 並沒有一個單鍵直接輸出「Rolling-shutter distortion ratio（捲動快門畸變率）」的獨立內建指標，而是必須搭配動態硬體設備拍攝「傾斜偏移（Skew）」或「感測器讀出時間（Readout Time）」，再透過 Imatest 的幾何分析模組（如 SFR / Checkerboard / Distortion）量測像素位移量並換算得出。  
捲動快門（Rolling Shutter）是因為 CMOS 感測器逐行掃描曝光，當相機或物體快速移動時，畫面頂部與底部的曝光時間差會導致垂直線條產生傾斜（Skew）。  
以下是使用 Imatest 工具鏈進行完整驗證與計算的兩種標準做法：  

### 方法一：利用動態設備與斜邊角度直接測量（最接近實際拍攝情境）
此方法透過讓測試圖卡或相機以「已知的等速」橫向移動，直接測量垂直線條在畫面中傾斜的角度（Skew Angle）與水平位移比例。
1. 硬體與圖卡準備
    - 運動模擬設備：使用 Imatest 官方硬體 Linear Motion Blur Module（線性運動滑軌模組） 或 Motorized Gimbal（雙軸電動雲台），設定精確的水平等速移動速度（V，單位：mm/s 或 deg/s）。
    - 測試圖卡：使用具備標準垂直黑白色塊或網格的圖卡（例如 SFRplus 或 Checkerboard），確保圖卡在靜止狀態下垂直邊緣與感測器垂直軸對齊。
2. 拍攝與 Imatest 分析步驟
    1. 拍攝動態影像：啟動滑軌或雲台進行水平等速移動，同時觸發相機拍攝一張或多張測試影像（建議同時拍一張靜止基準圖作為對照）。
    2. 匯入 Imatest 模組：將影像載入 SFR、SFRplus 或 Checkerboard 模組。
    3. 提取邊緣傾斜角度（Edge Angle）：
	    - 在 SFR 或 SFRplus 的分析結果中，軟體會精確計算出每個斜邊的 Edge Angle（邊緣傾角，單位：度 deg）。
	    - 比較「動態拍攝的邊緣角度 $θ_{moving}$」與「靜止基準的邊緣角度 $θ_{static}$」，兩者差值即為捲動快門造成的傾斜角 Δθ。
	    - 若使用 Checkerboard 模組，可直接匯出 JSON/CSV 數據中的角點座標（Corner Coordinates），計算最頂端角點 ($X_{top}$, $Y_{top}$) 與最底端角點 ($X_{bottom}$, $Y_{bottom}$) 的水平偏移像素 Δ X。

3. 計算 Rolling-shutter Distortion Ratio
取得數據後，業界通常透過以下公式換算畸變比例（Skew Ratio）：  
### Rolling-shutter Distortion Ratio (%) =$\frac{\Delta X}{\Delta Y} X 100\%=tan (\Delta \theta ) X 100\% $  
####    - Δ X：物體頂部與底部的水平偏移像素（Pixels）
####    - Δ Y：物體在畫面中所佔的垂直高度像素（Pixels）
####    - Δθ：Imatest 測得的動態與靜止垂直邊緣角度差
### 方法二：透過 LED 計時器測量 Readout Time 進行推算（最精準的感測器規格驗證）
若要排除鏡頭畸變或機械速度誤差，精確驗證感測器本身的捲動快門效應，需先測出感測器的整幀讀出時間（Frame Readout Time, \(T_{readout}\)）。
1. 硬體與軟體準備
    - 專用設備：使用 Imatest Camera Timing System LED Panel V5（LED 陣列計時器）（內建 110 顆高速閃爍 LED，精度可達微秒 μ s）。
    - 分析模組：使用 Imatest 內建的 LED Timing / Camera Timing 分析工具。
2. 驗證與換算步驟
    1. 拍攝 LED 面板：將 LED 面板充滿整個相機視野（FOV）並進行拍攝，設定高速掃描頻率（例如每 100 μ s 亮一顆燈）。
    2. Imatest 判讀 Readout Time：將影像載入 Imatest 的計時分析工具中，軟體會根據畫面最上方第一排亮燈與最下方最後一排亮燈的時間差，自動計算出該解析度與幀率下的 Readout Time, $T_{readout}$。
    3. 換算特定速度下的畸變率：得知 $T_{readout}$ 後，即可針對任何規格書要求的目標物體移動速度$V_{pixel}$，單位：Pixels/sec），精確算出對應的捲動快門畸變率：  
$\text{Distortion\ Ratio\ (\%)}$ = ${V_{pixel} X T_{readout}}/{H_{sensor}}$

 - $(H_{sensor})$：影像感測器的垂直總像素高度（例如 1080p 為 1080）

### 實務測試注意事項
- 排除光學桶形/枕形畸變干擾：若測試鏡頭本身有明顯的光學幾何畸變（如廣角鏡頭），量測斜邊角度時應盡量選取靠近畫面垂直中心軸的邊緣，或是先透過 Checkerboard 進行光學畸變校正後，再計算水平偏移量 Δ X。
- 快門曝光時間（Exposure Time）設定：測試時需將曝光時間調短（建議 < 1/500s 或搭配高亮度光源），避免動態模糊（Motion Blur）過度擴散導致 Imatest 無法精準定位邊緣中心點。
### 13. Thermal-state SNR(熱態信噪比) 
當 CMOS 感測器溫度升高時，暗電流雜訊（Dark Current Noise）與熱雜訊（Thermal Noise）會顯著上升（通常溫度每上升 6°C～8°C，暗電流會翻倍），直接拉低影像在暗部與中灰階的 SNR。
以下是完整的測試驗證流程與數據判讀步驟：

1. 測試環境與「熱穩態（Thermal-state）」條件建立

要準確測出熱態 SNR，前期溫控與相機運行條件必須嚴格定義：
- 環境控制（二選一）：
	- 高溫環境箱（Thermal Chamber）：將相機模組置於具備光學視窗的恆溫箱中，設定目標工作溫度（例如車載或戶外安防常見的 60°C、70°C 或 85°C），靜置 30～60 分鐘 確保感測器本體溫度達到熱平衡。
	- 連續高負載自熱（Self-heating Soak）：在常溫（25°C）下，讓相機以最高解析度與最大幀率連續錄影或串流 30～60 分鐘（直到機身或 ISP 溫度感測器讀數不再上升），模擬實際長時間運作的熱穩態。
- 冷態基準對照（Cold-state Baseline）：強烈建議在相機「剛開機（常溫 22°C~25°C）」時先拍一組基準圖，以便與熱態數據進行衰減量（Δ SNR）比對。
- 固定拍攝參數：測試過程中必須鎖定曝光時間（Shutter Speed）、類比增益（ISO / Gain）與白平衡，並關閉或固定多幀降噪（3DNR），避免 ISP 自動調整參數掩蓋熱雜訊的真實惡化程度。

2. 測試圖卡與 Imatest 模組選擇
根據測試目標（評估終端成像表現 vs. 評估純感測器暗電流），選擇對應的圖卡與模組：

| 測試目的 | 推薦測試圖卡 | 對應 Imatest 模組 | 測量重點 |
| ---- | ---- | ---- | ---- |
| 評估完整灰階 SNR 衰減（含 ISP 處理） | 灰階卡（OECF / Stepchart） 或 24色卡（ColorChecker） | Color/Tone Interactive 或 Color/Tone Auto（舊版為 Stepchart / Colorcheck） | 量測各灰階區塊的 SNR (dB) 與 Temporal Noise（時間雜訊） 隨溫度上升的下降幅度。 |
| 評估純感測器熱雜訊與暗電流（RAW 檔） | 全黑蓋鏡頭（Dark Frame） 搭配 均勻灰板（Flat Field） | Flat Field 或 Sensor Noise (PTC) | 排除光學與 ISP 干擾，直接量測 Dark Noise（暗雜訊） 與 DSNU（暗訊號不均勻度）。 |

3. Imatest 軟體操作與驗證步驟（以 Color/Tone 模組為例）

- 1. 拍攝連續多張影像（計算時間雜訊必備）：
	• 熱雜訊屬於隨機時間雜訊（Temporal Noise）。在達到熱穩態後，於同一條件下連續拍攝 2 張（或 8 張以上）完全相同的測試圖卡影像。
- 2. 匯入 Imatest 模組：
    - 開啟 Imatest 主程式，點擊 Color/Tone Interactive（若需批次比對冷熱態多組檔案，建議使用 Color/Tone Auto）。
    - 在讀檔視窗中同時選取這 2 張（或多張）熱態影像，並勾選開啟 Temporal Noise（時間雜訊） 計算模式（Imatest 建議雙圖相減法 2-file difference 即可精準分離隨機熱雜訊與固定空間雜訊）。
- 3. 確認灰階 ROI 框選：
	• 確認軟體自動框選了圖卡上的灰階區塊（例如 24 色卡最底排的 6 階灰階，或 20 階 OECF 灰階卡）。
- 4. 檢視 Noise 與 SNR 圖表：
	• 在結果視窗的顯示選單（Display）中，切換至 Noise & SNR 或 SNR (dB) vs. Exposure / Patch 圖表。

4. 核心數據指標判讀

在熱態 SNR 測試中，主要關注以下數據變化：
- SNR (dB)（訊號雜訊比）：
    - 重點觀察中灰階（18% Gray，約第 3～4 階）與暗部灰階（Dark Patches）的 SNR 數值。一般業界規範會要求熱態下的中灰 SNR 仍需大於特定門檻（例如 > 30 dB 或 > 35 dB，視產品等級而定），且與冷態相比的衰減量 Δ SNR 不得超過規格（例如 < 3 dB）。
- Temporal Noise（時間雜訊）與 Fixed Pattern Noise（固定模式雜訊）：
    - 透過多圖分析拆解出的 Temporal Noise 直接反映熱激發造成的隨機電子噪點；若熱態時畫面出現大量「熱噪點（Hot Pixels）」，則會反映在 Fixed Pattern Noise / DSNU 的急劇升高上。
- Dynamic Range（動態範圍，基於 SNR ≥ 1 或 SNR ≥ 10）：
    - 由於熱雜訊會抬高暗部雜訊底噪（Noise Floor），熱態下的有效動態範圍通常會比冷態縮減（例如從 11 stops 降至 9.5 stops）。
